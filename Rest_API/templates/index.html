☕ Cafe API Documentation

Welcome to the Cafe REST API. Use the endpoints below to access the data.

GET /random

Fetches a random cafe from the database.

http://127.0.0.1:5000/random

GET /all

Returns a list of all cafes in the database.

http://127.0.0.1:5000/all

GET /search

Search for a cafe by location. Requires a loc parameter.

http://127.0.0.1:5000/search?loc=London

POST /add

Add a new cafe to the database. Send data as x-www-form-urlencoded.

http://127.0.0.1:5000/add

PATCH /update-price/<cafe_id>

Update the coffee price of a specific cafe. Requires new_price parameter.

http://127.0.0.1:5000/update-price/1?new_price=£3.50

DELETE /report-closed/<cafe_id>

Delete a cafe from the database. Requires an api-key parameter.

http://127.0.0.1:5000/report-closed/1?api-key=TopSecretAPIKey
